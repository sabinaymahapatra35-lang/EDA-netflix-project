# 📊 Netflix EDA Project

## 📌 Objective
This project performs Exploratory Data Analysis (EDA) on the Netflix dataset to uncover patterns, trends, and insights about Movies and TV Shows available on Netflix.

---

## 🚀 Live Dashboard
👉 https://eda-netflix-project-8ca5alyguvw4pbpa6cdmod.streamlit.app/

---

## 🛠️ Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

---

---

## 📊 Key Features
- Data Cleaning and Preprocessing
- Handling Missing Values
- Data Visualization
- Interactive Dashboard using Streamlit
- Filters for Type, Country, and Year
- Search functionality

---

## 🔍 Key Insights
- Netflix has more Movies than TV Shows  
- Most content is produced in the United States  
- Drama and International Movies dominate  
- Majority of content is rated TV-MA  
- Content growth increased significantly after 2015
